# M7 — Monetization (design note)

*Shipped July 2026. Done criteria from `docs/03-roadmap.md`: a real so'm payment
upgrades an account end-to-end (sandbox + production paths).*

## What shipped — the moat

Local payment rails no global competitor supports (the core edge from the market
research), priced in so'm.

**Plans** (`app/services/plans.py`): free, premium_monthly (29,000 so'm), premium_yearly
(199,000), family (349,000, 6 seats) — the pricing from the product spec.

**Payme Merchant API** (`app/services/payme.py`): the full JSON-RPC 2.0 handler Payme's
servers call — `CheckPerformTransaction`, `CreateTransaction`, `PerformTransaction`,
`CancelTransaction`, `CheckTransaction`, `GetStatement` — with HTTP Basic merchant-key
auth, the 0→1→2 / −1 / −2 order state machine, idempotent retries, tiyin-exact amounts,
and Payme's error codes (−32504 auth, −31001 amount, −31050 account, −31003 txn,
−31008 state). Perform grants the subscription; cancel-after-perform revokes it.

**Click Merchant API** (`app/services/click.py`): Prepare + Complete with **MD5
signature verification** (the exact `sign_string` concatenations), order state, and
Click's error codes. Complete grants the subscription.

**Checkout** (`app/services/checkout.py`): base64 Payme redirect payload + Click query
URL builders. `POST /billing/checkout` creates a pending `Payment` order and returns the
hosted-checkout URL.

**Subscriptions** (`app/services/subscriptions.py`): activate/extend (re-buying before
expiry stacks days, never loses time), family membership, cancel. `is_premium` powers
gating — **premium flips the AI daily quota from 5 to 200** and unlocks premium surfaces.

**Referrals** (`app/services/referrals.py`): a 7-char code per user, entered at
registration (`?ref=` funnel); when a referee first pays, **both** get 30 days of
Premium — once, anti-fraud (tied to first payment, not signup).

**Sandbox** (`/billing/sandbox-activate`, `PAYMENTS_SANDBOX`): a clearly-labeled demo
path to activate Premium without a live gateway, so the whole flow is demonstrable now;
disabled in production with one flag.

**Web**: `/pricing` (plan cards, Payme/Click pay + demo activate, current-plan badge),
`/billing` (subscription status, cancel, referral code with copy + invite stats),
referral-aware registration, header 💎, premium reflected in the AI quota pill.

## Decisions & tradeoffs

- **Gateway protocols implemented for real, tested by simulating the gateway.** I can't
  hit live Payme/Click here, so the tests *are* the gateway — they build signed/authed
  requests and assert the full state machine. This is the honest way to ship an
  integration without production credentials.
- **Amounts in tiyin** (so'm ×100) on `Payment` for exact Payme reconciliation.
- **Sandbox path, clearly labeled**, rather than faking a gateway response — lets the
  premium flow be shown end-to-end while the real endpoints wait on merchant onboarding.
- **Referral reward on first payment, not signup** — prevents farming.
- **Premium = quota flip + gating**, not a parallel feature system; `is_premium` is the
  single source of truth.
